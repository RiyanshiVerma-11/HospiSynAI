⚡ If the Speech API is not producing text:

  1. Test in Microsoft Edge: Open http://localhost:3001/speech-test.html in Microsoft Edge! Edge uses Microsoft Azure Speech instead of Google, and works when Google Speech servers are blocked or failing.
  2. Check Chrome Mic Settings: Open chrome://settings/content/microphone in Chrome URL bar, and make sure the correct physical microphone (e.g. Realtek / Headset) is selected, NOT "Stereo Mix" or "Virtual Cable".
  3. Windows Sound Settings: Press Win + I → System → Sound → scroll to Input → check that your mic volume slider is at 85-100% and not muted.
  4. VPN / Hotspot: If connected to a VPN or restricted network, Google's speech recognition servers may be blocked. Try disabling VPN or switching to mobile hotspot.
